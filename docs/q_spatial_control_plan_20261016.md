# Fontify / Run B Fix：Q 空间调制与笔法保真预实验方案

**状态**：实验计划，尚未实现或运行。**基线**：2026-10-15 修复数据的原 edge Run B Fix，best epoch 50，checkpoint SHA256 `57ac8276e3468ad92ce2aff033736128b33862a4f922618c51910717166ae852`。**明确排除**：Tip、旧数据 Run B、G Scale s2–s5 作为训练初始化；第二轮大面积目标图遮盖与像素级补全。

## 0. 科学问题与已知依据

**待检验的假设**：当前 JT 头学习到一定的部件布局，但由槽位占用构造的显式 `G` 很难让生成图执行夸张的部件拉伸；若将预测布局直接用于调制更有效的 JT `Q` 空间特征，并使后续渲染可读取参考书法笔法特征，能否提高**部件尺度执行能力**而不牺牲细笔锋、短细笔画和连续性？

项目已有证据：Run B Fix 诊断 `J(normal)=0.482800`，`J(no_G)=0.481254`，`J(no_Q)=0.494899`；这里的 no_Q 只取消 Q 在最终融合残差的**直接贡献**，并不删除头内 Q 或 Q 对槽位/G 的计算。G Scale 五阶段后，受控占用尺度变化≥20%时，生成图横/纵尺度绝对变化中位数仅约 0.210% / 0.167%，横/纵 gain 仍约 0.01136 / 0.00758。这些证据支持**值得检查 Q 的直接贡献通路**，并不保证对 Q 做几何变换会成功。

**首轮要回答三个可分辨的问题**：
1. **几何控制**：仅在固定模型的 Q 直接注入位置施加可控空间变换，部件大小是否变化？与之前的 G 控制是否有实质区别？
2. **生成瓶颈**：若 Q 变换几乎无效，而 Decoder 入口主干特征变换有效，瓶颈位于什么位置？
3. **笔法质量**：一旦出现尺度变化，是否造成笔锋圆化、墨团、断裂、重影或局部内容错配？

## 1. 模型图与边界（先核对代码，再动手）

现有 Run B 全遮前向的必要路径为：

```text
电脑目标字 + 参考书法字（部署时真实可用的输入）
            │
       全遮前向 / ViT
            ├── F_full：4个深层tap的下半目标token，约[B,784,3072]
            └── JT头：Q（[B,784,256]）；4槽预测 M_k、exist_k、role_k
                        └── G（[B,784,256]）
      [Q,G,类别概率等] → 原融合投影(532→3072) → residual
                  F_dec = F_full + residual
                         ↓
                       Decoder → P_full
```

- `Q` 是 **JT 头内部的混合空间特征**，不是 `F_full`，也不是像素笔法图；`G` 来自槽位与占用概率的空间聚合。注意代码中具体 tensor 组织、归一化、残差、mask/role 拼接次序必须逐项定位并打印 shape，不能只凭图示替换。
- Q/G 在原融合投影中可能相互耦合（例如联合归一化）。所有 E1 干预都必须声明在**哪个具体张量、归一化前/后、concat 前/后**发生，不能将 `no_Q` 解释为“关闭结体头”。
- 本方案不把原 `P_pen` 的训练期 GT 可见片段作为推理输入；保留原前向①作为训练期辅助目标，但正式输出仍从全遮可用条件产生。

## 2. 阶段 A：零训练空间响应定位（必须先做）

**参数**：Run B Fix checkpoint；全部冻结，eval/FP32，`torch.no_grad()`；训练步数=0；固定随机种子、固定240条 val（101 JT + 139 BF）；216个 JT 有效 GT 实例。重点单独汇总报告已有的20条夸张候选，并按书家-字符去重；这20条是候选，不等于人工已确认的真标签。

**单实例干预**：仅对 JT 样本有效预测槽位，在其预测 soft 占用的质心附近沿 x 或 y 做逆映射采样，倍率 `0.75, 0.90, 1.00, 1.10, 1.25, 1.50`。选择/过滤规则只依赖预测存在性、占用面积及有效域，不依赖 GT；记录请求倍率、实际几何变换后支持域 σ 比、截断/重叠率。保留原 Q/F_full 副本作严格对照；实例 mask 使用软边界、插值和重叠归一化，避免硬切细笔画。ratio=1 完全绕过变换，保证数值恒等。

| 组别 | 具体干预 | 固定量 | 目的 |
|---|---|---|---|
| A0 | 原 Run B Fix `predict_full` | 全部 | 统一基线，逐值对账 |
| A1 | **Q-direct**：只对送入 `532→3072` 直接融合路径的 Q 做局部空间重采样 | JT 头上游、槽位、G、存在性、类别、主干 F_full | 验证 Q 的直接残差路径是否能执行部件伸缩 |
| A2 | **G-only**：相同实例、倍率和度量，只改变 G 的占用支持 | Q、槽位向量、类别、F_full | 与现有 G 失败路径对照，确保不是干预口径不同造成错觉 |
| A3 | **F-only**：直接对进入 decoder 的下半主干 `F_full` 做相同尺度的局部空间重采样 | JT Q、G及原残差 | 正控制：Decoder 对携带内容的主干空间特征是否敏感；不等同可部署方案 |
| A4 | **Q+F**：对 Q 直接注入路径及 F_full 做对齐变换，保持 G 原样 | 槽位、类别、网络参数 | 验证两种空间特征的一致变换是否能保留内容，仍属于只读干预 |
| A5 | 等面积随机/错位实例区域施加 A1 变换 | 相同幅度、面积分布 | 排除“随意扰动特征就能改变尺度”的伪控制 |
| AO | 仅诊断中用 GT 布局指定空间区域 | 其他参数 | 上界/敏感性分析，不可作为推理结果或主表胜出组 |

**关键要求**：A1 操纵的是已经计算好的 Q **直接注入输入**，不能重新运行 JT 槽位预测，否则 A1 同时改变 G，无法定位 Q；A3 应绕开 Q/G 对 `F_full` 的直接改动，真正区分主干和残差。此前 G Scale 也对主干特征做过 G 驱动采样，A3 仅是**同输入同口径的正控制**，不得包装为首次尝试。

**结果记录**：正常生成、变换后的占用支持、Q/G/F 局部差异、最终生成、GT（只展示/评分）；连续响应曲线及失败案例。

## 3. 阶段 A 的定量指标和进入训练门槛

**尺度执行（主指标）**：每个有效实例、方向 d∈{x,y} 统计 `gain_d = Δlog σ_pixel,d / Δlog σ_support,d`。仅用实际几何尺度变化≥20%的非零干预汇总主表（仍保留所有原始条件）；单独报告增大与缩小的方向正确率、符号相反比例、中位数/IQR/分位数、边界裁切率及无效实例数。沿用固定 GT Voronoi 的 224px 像素 soft sigma（与 448px 坐标注明换算），同时使用固定 ROI、硬前景阈值、部件邻近区域强度图的敏感性检查；Voronoi 不是预测实例的真实分割，不可过度解释。

**图像/结构**：原定义的 JT L1、BF L1、`J`（质心、logσ、shape 分项）、S；报告局部 edge 梯度、细短笔画连通性、重影/多余墨迹率、被搬移部件的细笔锋清晰度人工评分（盲看相同样本/相同放大比例）；局部 high-frequency 仅用于**评测**，不先改变训练目标。

**预先登记的探索性 go/no-go**：
- 若 A1/A4 出现**明显超过 G Scale 原约0.01 gain**的、方向一致的部件尺度控制（建议把中位 gain ≥0.10、方向正确率 ≥70% 作为第一轮优先信号），且非局部破坏、BF 质量系统性退化不可接受，则可进入阶段 B。这是**人为设定的资源门槛，不是统计显著性标准，也不是理论正确数值**。
- 若 A1 弱、A3 强：不要简单宣称 Q 不好，应优先研究从 Q/JT 布局到 `F_full` **内容特征搬运**的接口，训练 B2 的主干条件适配器而非仅调 Q 的512/3072残差。
- 若 A1、A3、A4 均弱：停止大规模训练，先排查采样 grid/坐标、真实形变幅度、Decoder 的局部感受野与预训练分布问题。
- 任何组若有几何 gain 但笔锋出现大面积重影、断裂或削尖退化，只报告控制成功/画质失败，不判为通过。

## 4. 阶段 B：通过门槛后训练轻量布局条件适配器（本次只规划，不默认执行）

**核心结构**：不要对目标 RGB 像素进行再次大范围遮盖或 inpainting。JT 头先由全遮输入产生 `Q, S`；让 S 指导第二阶段对**feature-level 内容特征**做部件级空间分配，并利用可见书法参考字特征进行笔法调制，最后一次 Decoder 输出最终像素。

- **B1：Q 条件空间适配器**。只在 A1 有响应时启用。输入 `Q、S、F_full`，输出 `ΔF`，由零初始化的残差门控 `F'_dec = F_dec + γ·ΔF` 注入，γ初值0；结构须有显式**按实例重采样/内容路由**，不能仅将 S 拼接进 MLP 后希望网络自行学尺度，否则与已失败的 G 残差实验差异不足。实际出图仍由 `F_full` 的原内容通道承担。
- **B2：主干内容特征的 JT 条件路由**。若 A1 弱/A3 强，选择此组优先；基于预测 M/slot 做局部位置到位置的特征采样或小规模 cross-attention，让目标空间位置能从其他内容 token 取得笔画信息。**注意**现有 JT 只提供目标部件区域，并没有显式的“电脑字源部件 ↔ GT目标部件”精确对应，不能假定一个仿射 warp 就能正确搬运所有笔画；需让路由学习对应关系或增加来源查询，且训练输入不能包含 JT GT。
- **B3：参考笔法适配器（可选后续）**。仅当 B1/B2 展现几何收益但损失细笔锋时，增加从实际可见的上半书法参考字抽取的局部多尺度高频特征作为 K/V 或调制条件。保留原电脑目标字内容约束；不复制参考字特定笔画作为目标字 GT，不通过 GT 可见目标区域训练/推理作弊。

**初始冻结**：ViT、JT 头、原融合层、原 Decoder 均冻结；只训练新 adapter。原 Q 提取参数冻结不表示经过联合 LayerNorm/新 adapter 后的“有效 Q 贡献”数值恒定。若 adapter 有收益但像素执行仍不足，才考虑为第二阶段使用**独立的**局部 Decoder 适配器或 LoRA；不可随意解冻共享 Decoder 后又声称第一阶段 `P0` 不变。

**训练数据/损失**：保持 Run B 三池、BF/JT 配对、修复后的数据与原 edge 协议；主输出全遮 `P_final` 用原 `L_full` 图像损失（recon + Gram + edge）和仅 JT 的 `J`。`L_pen` 作为原随机/BF 遮盖训练期辅助监督继续可计算，但冻结主干时对新 adapter **没有梯度**；`L_H` 同理对冻结 JT 头为常量监控。因而阶段 B 首轮 adapter 实际的优化来源主要是 `λ_full·L_full + w_J·J(P_final)`，不能把常数项表述为有效监督。沿用 Fix checkpoint 封存系数，不直接复制 Tip 权重。BF 的 `J/L_H` 均无真值，不构造零标签；如果以后开放 JT/ViT 梯度，BF 的图像损失对 JT 头的路径继续逐样本 detach。

**如普通图像/J 监督无法建立尺度响应**：再单列 B1b/B2b 消融，加入受控几何响应一致性约束（对同一样本施加小幅预测条件扰动，要求最终图实例尺度按一致方向变化）；不能把额外几何 loss 和新结构的收益混为一个因素。需要记录是否通过加墨、改笔画粗细而非移动部件“投机取巧”。

**训练预算建议**：新 adapter 先做1个小集合的可学习性检查（含夸张/普通和BF负例），再做5 epoch 冒烟；确认损失、梯度、尺度响应且未伤笔锋后，最多20 epoch 的受控探索。新模块 lr 初始可测试 `1e-4` 与 `3e-4`（具体需真实梯度和稳定性检查），其余模块冻结；clip3。所有组固定样本/数据增强/优化器步数与 seed，另有同预算原 Run B Fix 继续训练对照，避免把额外更新带来的 S 下降归给结构。

## 5. 数据使用、评测和防泄漏

- 第一阶段输入：**电脑目标字、书法参考字、目标字全遮占位**；第二阶段只读其预测 Q/S/F 及原输入可见的参考字特征，绝不读取真实目标字未遮盖像素。
- 第一次全遮前向不一定需要生成 P0：计划只计算 JT 布局与特征即可，第二阶段直接渲染；不需要图像级“先画后擦再补”。
- 240条固定旧val用于和既有 Q/G/G Scale 结果对账，可用于探索，但过去已反复使用，不能充当新的独立泛化测试。模型选择在**训练数据中划出的、按书家-字符尽量隔离的诊断集**完成；最终如果还有独立未使用的测试数据，再做锁定配置确认，不将历史240结果宣称成新数据泛化。
- 单独汇报101JT、139BF、20条夸张候选及按书家-字符去重；实例主表216项，另记录有效阈值后真实数量。失败数、越界数、预测存在性低样本不可静默删除。
- 先验预测类别是**方位角色**，不等同于笔画ID或完整部首语义；28×28 patch-any 占用不是像素级笔画 mask，任何“精确笔法生成区域”的说法都必须加限定。

## 6. 工程验证、交付与停止条件

**建议新增而非修改默认训练路径：**
- `tools/probe_q_spatial_control.py`：冻结 checkpoint，精确 hook Q/direct residual/F_full，A0–A5/AO 的 paired 干预。
- `util/q_layout_warp.py`：软占用质心、坐标网格、`grid_sample`、重叠归一化和身份变换；严格标注 `[B,28,28,C]` 与 `[B,N,C]` 的重排及 reference/target 上下半 token。
- `tools/evaluate_q_spatial_probe.py`：尺度 gain、对应区域、J 分项、L1/S、edge/shape 与配对差。
- `models/q_conditional_adapter.py` 与 `tools/train_q_conditional_adapter.py`：通过 A 阶段门槛后再实现 B。
- 产物统一进入新目录 `outputs/q_spatial_layout_runb_fix_20261016/`，含 `README.md`, `config.json`, `provenance.json`, `per_instance.csv`, `per_item.csv`, `response_curves.csv`, `summary.md`, `index.html`, `figures/`, `sha256_manifest.json`。

**阻断性检查**：
1. A0 与原 `predict_full` 按相同精度、数据逐值对账；ratio=1 的所有控制与 A0 相等（明确 FP32 容差）；仅下半目标 token 被变换，输入其它三个参考/电脑格不变。
2. A1 改变 Q 的直接注入路径时，slot/G 的预测值 **逐值相等**；A3 干预主干 F 时 Q/G 不变；真实 spatial transform 量必须被测到，不能只根据请求倍率推测实际变化。
3. 所有变量无 GT 像素/GT 占用渗入（AO例外且强制隔离）、无隐式“训练 GT 部分可见，推理全遮”差异。
4. 无训练阶段 checkpoint 前后SHA完全一致，参数无更新；训练阶段检查冻结/optimizer param group/DDP static_graph，阶段变更重建 optimizer/DDP。
5. BF L1 与细笔锋失败案例、JT J/尺度 gain 全量给出；生成样本颜色范围/归一化/输出指标口径与原 Fix 一致。
6. 未满足 A 阶段控制有效性和画质门槛，则**停止**，不自动追加大模型训练或开放 ViT。

## 7. 最终决策表

| A 阶段观察 | 最合理的下一动作 |
|---|---|
| A1明显控制尺度，画质基本可用 | 优先 B1：Q 条件适配器；保留参考笔法特征接口 |
| A1尺度有效但笔锋受损 | 小范围 B1，再与 B3 参考高频适配做单变量比较 |
| A1很弱、A3显著有效 | B2：JT 指导 F_full 内容位置路由，**不是继续做 G 残差缩放** |
| A1/A3都弱 | 停止训练，检查坐标实现、特征空间与 Decoder 空间响应 |
| 响应很强但与 JT 布局无关（A5相近） | 视为非特异性特征扰动，不能证明部件可控 |

**一句话原则**：先证明 **“JT 预测几何能驱动哪一条真正带有字形内容的空间特征路径”**，再训练；整个过程不依赖大面积遮盖补全，并把**部件伸缩**和**笔锋保留**作为独立且同时必须达标的目标。
