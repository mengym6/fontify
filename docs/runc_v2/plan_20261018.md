## 1. 为什么重做 Run C 阶段一：已验证的 v1 失败模式

Run C v1（`codex/structure-first-bifa`，源码 `10227342e59405db631967df37fe945eb23670b8`）从 Run B Fix best 初始化；ViT 冻结，训练 Head / Fusion / 新 adapter / 旧 Decoder，`Gaussian(7, sigma=1.5, reflect)` 只作 GT loss target，340 次更新，未启动 BF Refiner 正式训练。结果属于单 seed、旧 240 条固定验证集，**不是泛化证据**。

| 指标 | 原 Fix | v1 step85 | v1 step340 | 主要观察 |
|---|---:|---:|---:|---|
| `J(P0)` ↓ | 0.482800 | 0.469793 | 0.478063 | 短暂改善，不持续 |
| `P0 logσ` ↓ | 0.233224 | 0.221897 | 0.231273 | step85 最好，后续回退 |

**不能得出的结论**：不能断言 ViT 冻结是唯一原因；不能断言新 Cross-Attention 无用；不能因粗图像素指标变差而证明结构专用低分辨率表示失败；不能把 v1 的 `J` 与 v2 重新定义的粗图指标直接横向比较。

旧历史资产保护：`models/runc_20261017_coarse340_v1/`、`outputs/runc_20261017/`、服务器 `/root/autodl-tmp/fontify_dual_runb/outputs/runc_20261017*` 只读；不得覆盖、清理或写入 v2 结果。预训练 checkpoint 和 Run B Fix best 均只读且记录 SHA256。

## 2. 端到端模型：明确阶段一与阶段二的输入输出

```text
训练 / 推理均可获得：电脑目标字 + 同书家参考书法字及对应电脑字
                         │   [目标书法字区域始终全遮；不看 GT]
                         ▼
               Fontify MAE ViT（从 ckpt14 初始化）
                         │
               F_full / 参考特征
                         │
                         ▼
        JT Head（重新初始化，结体专门训练）
            ├── Q：空间表征
            └── S：4 slots × {存在性、软占用、方位角色等}
                         │
        结构查询 Z_S = Encode(S) + position（目标格点上）
                         │
           Cross-Attention（Query=Z_S，K/V=F_full,Q,参考特征）
                         │
                 Coarse Head（新建）
                ├── 112×112 连续墨迹密度 D0
                └── 112×112 粗占用概率 O0
                         │
              上采样 D0 → 448×448 RGB 粗图 P0
                     【阶段一】
                         │
               （仅阶段一验收通过后）
                         │
    在模型生成的 P0 上遮盖 BF 标注区域；绝不遮盖/可见 GT
       训练 BF 11 层；推理 S/P0 自动分块（差异暂留）
                         │
         冻结 MAE ViT 第二次编码 Masked P0
                         │
           新 BF Refiner（仅阶段二可训练）
                         │
            P1 = P0 + learned residual（最终字形）
                     【阶段二】
```

### 2.1 变量及尺寸契约（须 T0 源码核验）

| 变量 | 预期形状（单目标图） | 语义 / 约束 |
|---|---|---|
| `X` | 拼接上下参考/目标布局，通常 `B×3×896×448` | 目标书法 GT 在 encoder 输入中始终不可见 |
| `F_full` | 现有四抽头目标区域特征，历史示意 `B×28×28×3072` | **实际通道和 LN/融合接口以源码为准** |
| `Q` | 历史示意 `B×28×28×256` | JT Head 空间表征，不等同四槽占用 |
| `S` | 4 槽预测，空间尺寸约 `28×28` | 槽存在性、软占用、方位角色；尺度/质心可微派生 |
| `D0` | `B×1×112×112` | 连续墨迹密度，取值 `[0,1]` |
| `O0_logits` | `B×1×112×112` | 结构存在性 logits（辅助分支） |
| `P0` | `B×3×448×448`（目标下半单图） | 使用可微上采样和统一反归一化定义，供阶段二输入 |
| `P1` | `B×3×448×448`（目标下半单图） | 第二阶段最终输出，未启用时不参与阶段一优化 |

**避免严重概念错误**：`D0` 是**模型输出**，其 GT target 来自下采样；`S` 是预测而非 GT 布局。`P0` **绝对不能使用 `Downsample(GT)` 直接替代**。原 Run C 的完全低频 GT 只存在于监督端，不得作为任何部署生成条件。

### 2.2 Coarse Head 的最小可实现接口

1. 在 `28×28` 目标位置将四槽软占用、slot 存在性权重、预测方位角色编码为**带空间位置的 `Z_S`**；槽顺序应经 permutation-invariant 汇聚，不能假定 slot 1 永远是左部件。
2. 用 `Z_S` 作为 Query，使用预训练 ViT 的内容/参考/空间特征（含 `F_full` 与 `Q`，按真实接口投影）作为 K/V。首选复用已确认的轻量配置 **hidden=256、heads=4、1 cross-attention block** 作为起始实现，维度必须实际核验；**不**宣称它已经是最优。
3. 融合结果经轻量空间上采样网络输出 `D0` 与 `O0_logits`（可共用 trunk、分头预测）。新参数量、MACs、峰值显存和 token 数由 Agent 实测报告；不必复用旧 Decoder 的最终卷积生成层。
4. 禁止直接提供一条未经 `Z_S` 交互的高容量 `F_full → D0` shortcut；允许必要的残差/归一化，但必须能通过受控条件扰动证明输出确实响应结构信息。
5. `D0` 用 `sigmoid` 或等价稳定方式限制为 `[0,1]`；`P0` 由 `1-D0` 转成白底黑字，使用**有梯度**的 bilinear 上采样至 `448×448`，通道复制成 RGB 后按原数据流的一次 ImageNet normalize 接入第二阶段。所有图像指标计算前须反归一化一次。
6. `O0` 仅为粗占用辅助监督/诊断，不强制硬二值化写回 `P0`；否则会损失梯度和造成锯齿。是否最终把 `O0` 用作软空间引导可在 smoke 验证后说明，但未经用户同意不额外增加复杂输出依赖。

## 4. 结构专用粗图 target：明确数学定义与拓扑检查

以下公式均作用于单个 `448×448` 目标字，首先统一为浮点灰度 `[0,1]`，**1=墨迹，0=白底**，避免原框架的 ImageNet normalize 和黑白极性弄反。

记墨量图 `I_GT = 1 - gray(GT)`；以 `4×4` 不重叠区域构造 112 分辨率监督：

$$
D_{GT}=\operatorname{AvgPool}_{4\times4}(I_{GT}), \quad D_{GT}\in[0,1]^{112\times112}.
$$

构造像素墨迹存在性 `B_GT = 1[I_GT > τ_ink]`，再得到粗占用：

$$
O_{GT}=\operatorname{MaxPool}_{4\times4}(B_{GT}),\quad O_{GT}\in\{0,1\}^{112\times112}.
$$

其中 `τ_ink` **不能未经核查直接定值**：应优先对齐仓库现有 JT/GT 前景阈值与去噪约定，在固定 train 审核集记录不同阈值下的墨量占比及孤立噪点。`D_GT` 不需硬二值化；`O_GT` 只用于辅助损失和可视化。

**阶段一输出**：

$$
P_0 = 1-\operatorname{Upsample}_{\mathrm{bilinear}}(D_0;448,448).
$$

`P0` 统一为白底黑字，再转成三通道供第二阶段使用。低分辨率输出旨在减少建模高频笔锋的压力，**不意味着阶段一可以漏掉笔画或者乱合并部件**。

### 4.1 与 v1 的关键区别

- v1 在 `448×448` 高分辨率像素输出上拟合一个轻度 Gaussian 低通的 GT，仍可学习大量细节。
- v2 显式限制 Coarse Head **仅输出 `112×112` 结构密度图**，再上采样得到 `P0`；另以 `O_GT` 防止小结构从密度目标中消失。这是表示空间改变，不能只替换 `sigma` 就称 v2。
- 第一阶段**不加入 Gram/style edge/局部高频 detail/GAN/Tip**。这些特征主要由第二阶段恢复。

### 4.2 实施前必须有的可视化及可达下界（无训练即可做）

在固定样本（至少包含“無、容、惟、雲、崇”与其他夸张左右/上下结构、细短笔画）上导出：

- `GT` 原图；`D_GT(112)` / 上采样密度 oracle；`O_GT(112)` / 上采样占用；现有 Run C v1 的 Gaussian GT；可选 `56×56` target 作为**只读视觉参考**，**不作为新训练配置**。
- 源目标 vs oracle 的 `J`、质心、`logσ_x/y`、shape，判断**仅仅降采样本身造成的不可消除结构误差下界**。若 oracle 已丢失“無”底部四点等不可接受的拓扑，**在新模型训练前停止，让用户选择是否提高分辨率/调整目标**，不可直接开始昂贵长训。
- 对细短笔画：报告小部件存在/消失率、合并/断裂的实例或连通域数量（阈值敏感性要说明）；不以像素 L1 替代拓扑核查。
- 不人为填写“连通率必须 95%”之类没有根据的经验阈值，必须提供 fixed samples 与量化对照供用户验收。

## 5. 阶段一新损失：Head 几何 + 粗图结构（需要重新标定）

记 `D0` 为预测连续密度，`O0_logits` 为粗占用 logits，`S` 为 JT Head 预测。

### 5.1 Head 专项损失

沿用当前匹配与多头监督 `L_H`（存在性、槽占用 BCE/Dice、方位角色），新增：

$$
\mathcal L_{H\text{-geo}} =
\alpha_{\sigma}\,D_{\log\sigma}^{\mathrm{head}}
+\alpha_c\,D_{\mathrm{centroid}}^{\mathrm{head}}
+\alpha_f\,D_{\mathrm{shape}}^{\mathrm{head}}.
$$

**实现细节**：

1. 沿用现有 JT slot-Hungarian 匹配与有效实例判定。对**匹配后的每个真实有效 GT 槽**，在 `28×28` 的**预测软占用**上计算可微的质心、横向尺度、纵向尺度（logσ）和归一化粗形状描述；GT 指标由同坐标下的 JT 实例墨迹生成。
2. 不允许在反传路径中 `threshold/argmax/detach` 占用图；仅 matching assignment/有效标记可离散、无梯度。
3. 对 `sum(p)` 极小、空槽、边界墨迹做 `eps` 稳定处理，既不能 `NaN` 也不能靠输出全空图规避损失。存在性 BCE/Dice 继续保护覆盖质量。
4. **尺度横纵分项分别报告**，尤其夸张结构；质心指标要分清绝对位置误差与原 `J` 的相对质心误差。原匹配和 slot permutation-invariance 必须保持。
5. `shape` 可以复用原 `J` 的标准化 8×8 质量分布思想，但须先按 Head 28 网格验证归一化、缩放与每槽质量一致性；如果无法可靠适配，不可假称与旧 `J` 逐值等价。

### 5.2 粗图损失

$$
\begin{aligned}
\mathcal L_{\mathrm{density}} &= \operatorname{SmoothL1}(D_0,D_{GT}),\\
\mathcal L_{\mathrm{occupancy}} &= \operatorname{BCEWithLogits}(O_{0,\mathrm{logits}},O_{GT})
\quad[+\,\operatorname{Dice}\ \text{仅若按原项目配置确认}],\\
\mathcal L_{J\text{-coarse}} &= J_{\mathrm{matched\ coarse}}(P_0,GT;\mathrm{JT\ instances}).
\end{aligned}
$$

`L_occupancy` 正负样本严重不均衡，需记录 foreground fraction 与梯度规模，并在多 batch probe 决定是否沿用 BCE+Dice；不要默认背景主导时 BCE 数值小即训练成功。

`J_coarse` 使用已有 JT GT 实例划分，在**同一评估尺度**比较部件相对质心、`logσ`、粗形状。必须同时输出：

- **训练口径**：在 `112×112` 相同粗图表示下预测与 oracle coarse GT 的 `J_coarse`，确保 target 可达。
- **原始几何口径**：上采样后的 `P0` 与原始 448 GT 的实际尺度和部件位置偏差，用于判定真实结构，而不是利用降采样/二值化降低报告数值。
- **oracle 地板**：上采样 `D_GT` 与原始 GT 的几何偏差，量化表示误差下界。

训练中使用何种 `J` 输入、哪一步先作 anti-normalization、GT-Voronoi 作用的坐标和 loss denominator，必须用单测标明，避免比较不同坐标/样本分母造成假收益。

### 5.3 各子阶段优化目标

**I-A（Head / 结体表征学习）**：

$$
\mathcal L_{\mathrm{I-A}} = \lambda_H\mathcal L_H +\lambda_g\mathcal L_{H\text{-geo}}.
$$

**I-B（固定 Head 的结构条件渲染）**：

$$
\mathcal L_{\mathrm{I-B}} =
\lambda_d\mathcal L_{\mathrm{density}}
+\lambda_o\mathcal L_{\mathrm{occupancy}}
+\lambda_{J,0}\mathcal L_{J\text{-coarse}}.
$$

**I-C（受控联合微调，可按验收决定是否执行）**：

$$
\mathcal L_{\mathrm{I-C}} =
\mathcal L_{\mathrm{I-B}}+
\lambda_H\mathcal L_H+
\lambda_g\mathcal L_{H\text{-geo}}.
$$

**梯度政策**：I-A 没有 Coarse Head 更新；I-B 阶段 ViT 与 JT Head 不更新，结构条件路径保留前向作用但 Head 输出停止梯度；I-C 在 JT 样本上按真实可微路径允许 Head 收到 `J_coarse`/density/occupancy 梯度，但必须同时受 `L_H/L_H-geo` 约束，避免再次发生 Head 尺度恶化却靠粗图端降 `J` 的情况。

所有 `λ` 与 `α` 仅代表待标定权重。**Run C v1 的** `low/J/H=1/0.0571819470/0.3125585722`、`J` 内部 `2.0985011631/0.2205788097/1` **绝不能直接复用**；旧 Fix 的权重也不得复用。需要多书家、多批次、真实 BF16/FP32 梯度范数、梯度夹角/抵消、占用稀疏性和梯度裁剪观测。标定依据是梯度，不是 raw loss 大小相似。

## 6. ViT 解冻与阶段 I-A/I-B/I-C 具体调度

本轮不把“冻结 ViT”或“全解冻 ViT”写死，而是按可解释性拆开。**所有阶段从同一 v2 训练轨迹衔接**；不允许 I-B 偷换回 Fix 初始化。

| 子阶段 | ViT | JT Head | 结构 Cross-Attn / Coarse Head | 优化目的 |
|---|---|---|---|---|
| I-A0：Head-only 健康检查 | **冻结**，极短 smoke | 训练 | 未启用 | 核查新 Head/损失是否可降，排除梯度 bug |
| I-A1：结体表征适配 | **部分解冻**与四抽头有关的少量深层 block，低 LR | 训练 | 未启用 | 让结体误差塑造 ViT 结构特征 |
| I-B：固定预测的结构渲染 | **冻结** | **冻结** | **训练** | 检查 `S` 能否引导粗图尺度/形状 |
| I-C：联合微调（条件启动） | 经批准的相同少量 ViT block 可低 LR 解冻 | 训练 | 训练 | 协调 Head 与 `P0` 真实几何 |
| 阶段 II：BF Refiner（以后） | **全部冻结** | **冻结** | **冻结** | 只训练新笔法细化参数 |

### I-A0 不代表要求长时间冻结

- 仅跑**受控短 smoke**：检查不看 GT、固定 tiny JT batch 能使 `L_H/L_H-geo` 下降、梯度有限且存在、Head scale 对几何变化敏感；以结构诊断为目的，不把 Head-only checkpoint 当新最佳基线。
- I-A1 对真实源码中四个 tap 的层号逐一映射（注意原资料有 ViT-B/ViT-L、0-based/1-based 两套记法）。默认候选是**在每个被取用 tap 之前选择极少数相邻 block（例如每个抽头末端 1 个）及其 norm/projection**进行训练；先列出完整参数名单、层位置与 param_count，让用户审核。不要无证据只解冻最末 2 block 却声称四个 tap 都适配，也不直接全解冻 12/24 block。
- 新 JT Head 学习率与被解冻 ViT 的 LR 分离，ViT LR **显著低于 Head**，需结合真实权重/梯度审计给初始配置；不把旧 Run C 的固定 `1e-4` 照搬给预训练 ViT。
- 冻结模块的 BN/dropout 状态、grad checkpointing、DDP static_graph、optimizer parameter groups 都需显式核验。

### 子阶段切换原则

- I-A1 至少能在固定训练/验证子集上让 **Head 占用、尺度/位置指标呈现可信的改善趋势**。若 train 都不降，优先排错；若 train 降 val 不降，定位过拟合与数据泄漏，不直接增加 ViT 解冻范围。
- I-B 必须同时检查 `D0/O0` 能否逼近低分辨率 oracle、`P0` 是否遵守 `S` 的几何规划，并排查极短笔画/点画缺失。
- I-C **仅在 I-A 与 I-B 分别可学习、且联合协调有必要时启动**。如果 I-B 达到验收，可跳过 I-C 而进入用户审阅。I-C 不得以牺牲 Head 尺度换取轻微的粗图 `J` 改善。
- 阶段 II 启动须用户对预测 `S`、低频 `P0`、夸张结构的主要失败案例和可达上界进行人工审查。

## 7. 评估、停止条件与防止误判

### 7.1 每个固定 checkpoint 的主要指标

| 类型 | 必须报告 | 验收含义 |
|---|---|---|
| JT Head | matched soft IoU、BCE/Dice、角色正确率、存在性召回 | 不能只靠尺度统计“投机” |
| Head 结构 | matched `logσ_x/y`、质心（绝对/相对）、归一化 shape、P50/P90/P95 | **第一验收层**，尺度为主要关注点 |
| 粗结构 | density Smooth-L1、occupancy BCE/Dice、`J_coarse` 分项、`P0 logσ_x/y`、部件相对位置 | **第二验收层**，模型生成粗图必须跟随 S |
| 表示误差 | oracle `D_GT` 上采样 vs 原始 GT 的 `J` / 小结构保留率 | 区分表示损失与模型学习失败 |
| 条件作用 | 固定 F/Q，改变/移除 S 时的输出变化、`∂P0/∂S` 可微探针 | 数值变化不自动代表正确几何响应 |
| 视觉 | `GT/D_GT/O_GT/S_GT/S_pred/D0/O0/P0` | 检查异常合并、消失、墨团、错位 |
| 工程 | source SHA、checkpoint SHA、seed、优化器 step、LR、有效 batch、dtype/cudnn | 可复现性及跨后端口径 |

所有结构几何必须在**相同标准**下复测；原 Fix 作为已有完整字形生成对照，不把其原始像素 L1/S 当作 v2 的主要目标。仍可只读引用 Fix 的 Head IoU `0.516329`、Head `logσ=0.346398` 等历史点，但必须注记新预训练初始化、架构、输出分辨率不相同；不能保证 v2 很快达到此水平。

### 7.2 必看的失败案例

固定显示“無”（底部点画、间距）、“容”（部件尺度/空间）、“惟”（左右夸张部件）、“雲”（复杂多笔画），再增加至少 8 个涵盖九书家、左右/上下、极端缩放的 JT 样本。对重复参考字/同字样本报告去重分组结果，不挑视觉上最好的一张代替统计。

### 7.3 可执行停机规则（非预注册统计阈值）

出现以下任一项立即停止当前子阶段并提交阻断报告：

1. GT 像素、JT GT mask/标签通过输入、Teacher forcing、调制或缓存进入任何部署前向；或阶段 I-B 用 oracle `D_GT` 代替模型预测 `P0`。
2. 新 checkpoint 的可训练参数未加载/随机初始化未记录；不小心加载 Run B Fix 或 v1 作为 v2 主权重。
3. stage-I dataloader 采入 BF-only、JT 实例增强错位、重名目标重复计数；或抽样漏掉某书家而没有报告。
4. `L_H-geo` 几乎没有有效梯度、no-S 与 normal 输出逐值一致且结构输入没作用、`D0` 不可微、所有 Refiner 参数错误地参与 stage I optimizer。
5. NaN/Inf、尺度/质心在空槽上爆炸、梯度累积或 DDP 的有效 batch/样本归一化错误。
6. **Head 几何明显持续恶化且 P0 只靠绕开 S 变好**；不得继续堆 epoch 试图掩盖矛盾。按连续 checkpoint（至少两次）有方向一致的退化及正常误差波动/置信区间作出审慎判断，不能以一个 batch 的噪声误判。
7. 低分辨率 oracle 已经不可接受地破坏关键结构，则在耗费训练前进行用户人工验收，不通过不进入新长训。

如果小样本 overfit 通过，而固定 JT val 停滞或变差，必须报告训练集/验证集双轨走势和书家-字符近重复情况；不能只给一个最低的历史验证指标，宣称泛化。

### 7.4 结构验收不是自动切换开关

至少同时满足：**Head 尺度与占用走势得到验证；`P0` 相对 oracle 的粗图与真实几何可接受；夸张尺度尾部和关键点画未系统性丢失；条件 `S` 真实影响生成；用户人工审阅通过。** 具体数值阈值不在不充分证据下硬定；Agent 须先给多快照曲线和 12 字并列图，让用户确认下一阶段是否开始。
