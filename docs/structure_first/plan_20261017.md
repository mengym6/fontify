### 0.1 已确定，不得擅改

- **基线**：修复数据的 Run B Fix **原 Edge 版本**，best epoch 50；不是 Tip、loss-search 或 G Scale 版本。
- **总体主链**：全遮部署输入 → MAE ViT 表征 → JT Head 预测 `Q/S` → 强化 `F/Q/S` 条件交互 → 结构粗图 `P0` → 对 `P0` 局部遮盖 → MAE 式 BF Refiner → 完整最终图 `P1`。
- **先结体、后笔法**是**模型执行依赖**：`P1` 的输入必须包含真实由阶段一预测的 `P0`，不得把“两个互不依赖的训练前向”冒充两阶段生成。
- **分阶段训练**：先训练结体和粗图，达到结构验收门槛以后再训练笔法细化；第二阶段初期**冻结整个阶段一**（含 ViT、JT Head、阶段一条件交互/粗图生成器），只训练新 BF Refiner 可训练参数。
- **粗图目标选 B**：`P0` 使用显式低频/结构监督，而不是按普通完整高频 GT 强制还原所有细节；但不得丢掉必要笔画拓扑。
- **训练期 BF 遮盖**：沿用当前 Run B / CalliPhase 已有 BF 语义遮盖采样协议，`--num_mask_annotations_bf 11`；**不聚合 polygon、不合并邻近标签、不另造 11 个方块**。
- **11 的准确含义**：从 BF `.npy` / annotation 的**非 `text` 语义标注层**随机抽取 11 个（应核实当前实际行为，包括不足 11 层、覆盖阈值和 patch 映射）。它不是“精确遮住 11 个互不重叠的 16×16 patch”，多个标注投影到 patch 后可重合。优先**复用既有采样实现**，不得重新写出语义不同的 mask 构造器。
- **训练期 BF 遮盖对象**：阶段一**生成的 `P0`**，绝不在 GT 目标图上留下可见真实像素供第二阶段编码。
- **损失**：阶段一更新为低频图像 + `J(P0)` + JT Head 的 `L_H`；阶段二更新为最终完整图像损失 + BF 遮盖区域的局部笔法损失 + 可用 JT 样本的 `J(P1)`。
- **推理方案 B**：推理时没有 BF 标注，先依据预测 `S` / `P0` 自动选择局部区域进行遮盖重建（可分块/分轮）。**训练 BF 选块与推理自动选块的分布不一致已知且被用户明确允许暂缓解决**；要完整记录，不能声称已消除，也**不准为消除差异私改训练的 11 层采样协议**。
- **消融**：如“不遮盖、直接细化 `P0`”等只列为后续研究计划，**本轮不抢先执行**。
- **GAN / Tip**：主方案不引入 GAN、Tip、额外高频损失大礼包；初版保持 Run B Fix Edge 系列的原有组件作为参照。

## 1. 目标架构与真实计算依赖

### 1.1 训练/推理共用的生成主链

```text
部署可用条件：目标电脑字、同书家参考字（及其对应电脑字），目标书法字区域全遮
                                   │
                                   ▼
                         Run B MAE ViT 编码
                                   │
                     F_full（四抽头）/ 参考特征
                                   │
                                   ▼
                  JT Head → Q / S（实例槽与空间布局）
                                   │
                                   ▼
         强化 F/Q/S 条件交互（必须超过原 G/Q 简单残差的能力）
                                   │
                                   ▼
                     Coarse Renderer → P0
                  【阶段一：结体规划 + 结构粗图】
                                   │
                         P0 + 预测 S + 参考
                                   │
                 局部 BF mask 作用在 P0 上
            训练：原 BF 标注采样 11 层；推理：自动结构分块
                                   │
                                   ▼
              Masked P0 → MAE 式 BF Refiner → P1
                      【阶段二：局部笔法重建】
                                   │
            P1 为完整最终书法字（不是仅有 11 层的拼贴图）
```

- **计算上的两阶段不要求将旧 `Forward 1` 与旧 `Forward 2` 简单换序**。阶段一需 Run B 原全遮条件；阶段二再次编码被遮盖的 `P0`，属于真正的第二个条件重建 pass。精确的 ViT/Decoder 权重复用方式先做源码审计。
- `P0` 是**模型自己生成**的结构粗图，训练和推理都不可换成模糊 GT 或 GT 局部可见图。低通 GT **只准作为阶段一损失目标**。
- `S` 在阶段一指预测的槽位存在性、粗占用、方位角色及可导出的相对位置/尺度/粗形状描述；**不要凭空当成现有 head 直接输出高精度笔画/完整部首 ID**。
- BF 标注用于**训练 mask 选择与训练损失**，不可作为模型推理输入；JT GT 仅用于阶段一 `L_H/J` 及阶段二 `J`。
- 新 BF Refiner 必须使用预测布局 `S` 或由其控制的输入，以及 `P0` 与风格参考；不能退化成在 GT 字上做常规 inpainting。
- 第二阶段输出 `P1` 允许整图可微细化，**局部区域给予更强监督**；不要硬编码所有未遮盖像素必须等于 `P0`，否则可能阻止修正跨 mask 边界的尺度/笔画错误。

### 1.2 与原 Run B 的增量（不得重复造轮子）

原 Run B 的 `P_full` **已经**使用 `F_full`、JT Head 的 `Q/G` 经融合残差送入原 Decoder。新增部分必须可识别：

1. `F/Q/S` 明确交互的**条件适配器**（作为阶段一改进；不能只是把旧融合复制一遍改名）；
2. 对 `P0` 的**低频结构目标**；
3. 对生成 `P0` 进行**真实的第二阶段 BF 语义遮盖**（不是旧训练前向对 GT 目标字局部遮盖）；
4. 从遮盖 `P0`、预测 `S`、参考特征输出 `P1` 的 BF Refiner；
5. 分阶段冻结、分池损失路由、训练/推理各自的 mask 构造。

实现上优先走**旁路 + 显式开关**，保留不启用时原 Run B Fix `predict_full` 的逐值一致性。条件模块的具体计算实现须先检查真实 `F/Q/G` 与 Decoder 接口，避免在读码前锁死维度、LN 位置或拼接顺序。

## 2. 数据与 mask 规范（特别重要）

### 2.1 数据池用于哪一阶段

| 数据池 | 阶段一 `P0` 低频图像 | 阶段一 `J(P0)/L_H` | 阶段二标注 BF 遮盖+局部损失 | 阶段二 `L_img(P1)` | 阶段二 `J(P1)` |
|---|:---:|:---:|:---:|:---:|:---:|
| 双标注 466 | ✓ | ✓ | ✓ | ✓ | ✓ |
| BF-only 352 | ✓ | — | ✓ | ✓ | — |
| JT-only 274 | ✓ | ✓ | — | 本轮默认不纳入 BF 局部训练 | — |

**阶段二首版训练样本为 BF 标注可用池（466+352）**。仅 JT 无 BF polygon，**不得伪称有 11 个 BF 语义区域**；它仍参加阶段一结构训练与阶段性结构验证。若确需让 JT-only 额外参加阶段二纯全图细化或自动 mask 训练，那是独立数据策略改动，**先请用户确认**，不得混入本轮主方案。阶段二整图 `P1` 的 JT 监督仍可通过双标注池中的 JT GT 生效。

### 2.2 训练 BF mask：完全沿用既有 11 层行为

- 核查 `data/pairdataset.py`、semantic mask 生成代码、参数脚本中实际路径及：`num_mask_annotations_bf=11`、`mask_coverage_threshold`、补齐/去重/空 mask 行为、同步几何增强、patch 映射。
- BF 的 `.npy` 是“非 `text` 标注每层一个区域”，采样单位是**BF annotation layer**；不得按“11 个笔画种类”理解。
- 在**与 GT 同坐标系**的 `P0` 上复用最终 patch 级 mask：选出的 11 层经过既有二值化/patch 化得到掩码 `M_patch`，它代表实际遮盖位置。保留原来的相交/覆盖阈值语义，不合并 BF polygon。
- 训练 loss 的局部监督区域要明确区分：`M_patch` 是实际遮盖（MAE 输入）；`M_pixel` 是将**实际遮盖 patch** 映射到输出图的像素区域（与 `valid` 取交），以免监督区域与遮盖区域错位。可以额外记录原 BF polygon 支持域，但不能仅用小 polygon 覆盖掉邻近实际遮盖 patch 的所有 loss 而不说明。
- 如果既有 BF mask 逻辑已经算出 `M_patch`，**优先复用其输出**；不可从已经变形的另一份图像上重新独立采样造成对齐错误。
- `P0` 不需计算图梯度流到 JT 头（阶段二冻结）；BF 图像/局部 loss 对阶段一所有参数应为 0 梯度。
- 选不足 11 层、mask 空/全覆盖、重叠、边界位置等情况，**严格复用现有规则**，记录“请求采样层数 / 实际非空层数 / 目标 patch 覆盖率”，不得默默跳过导致分母变化。

### 2.3 推理：用户已选 B，允许暂存分布不一致

- 推理阶段绝对**不能读取 BF/JT GT 标注**，也不能读取目标 GT 真实像素。
- 暂定可执行的最小推理路径：根据模型预测 `S` 的存在性/粗占用图及 `P0` 自身的墨迹空间信息，自动选出 patch-aligned 局部候选，遮盖 `P0` 并交给 BF Refiner；提供可配置的候选数量、覆盖阈值和重建轮数。**具体候选排序/遍历调度须在代码审计后记录为可复现配置，不得假称它与训练 BF 11 层采样等价**。
- 若推理采用多轮更新，后轮只允许读取**上轮模型自身输出**，不得混入 GT；避免同一批次的未更新/已更新区域处理顺序不确定，必须固定顺序和 seed。
- **已知未解决项**：训练时按真实 BF annotation 选 11 层；推理按预测结构/粗图自动选 patch，二者的 mask 分布、语义粒度与覆盖率不匹配。本轮作为**明确的研究限制**留待后续推理策略研究，不以它为理由改变用户选定的训练采样。
- 本轮推理实现的最低验收是“可运行、完全无 GT 泄漏、输出可复现、mask/输出可视化齐全”，**不是**宣称最终质量已与训练指标一致。

## 3. 新损失：阶段一与阶段二分别标定

### 3.1 阶段一：粗图结构学习

$$
\mathcal{L}_{0}=
\lambda_{\mathrm{low}}\mathcal{L}_{\mathrm{low}}(P_0,GT)
+\mathbf{1}_{JT}\lambda_{J,0}\mathcal{J}(P_0,GT)
+\mathbf{1}_{JT}\lambda_H\mathcal{L}_H(S,GT_{JT}).
$$

其中建议将显式低频目标实现为**可配置**形式（滤波核/方差/边界方式必须写入 config 与日志；本轮不臆定最佳数值）：

$$
\mathcal{L}_{\mathrm{low}}(P_0,GT)
=\operatorname{SmoothL1}\bigl(P_0,\operatorname{LPF}(GT)\bigr).
$$

- `LPF(GT)` 只能参与 loss target；**不得**当模型输入。
- 原 Run B 的 `J` 仍约束相对质心、横纵尺度 `logσ`、粗形状；**尺度优先于形状**，使用真实（未低通）GT 作为几何真值，按实际 `J` 函数输入要求处理生成图。
- `L_H` 仍按实例匹配计算预测槽存在性、占用及方位角色监督。
- **仅 BF 样本**必须在 head 导出的所有相关分支上确保 `detach`/参数梯度隔离（含 `Q` 与 `S` 的实际来源）；共享 ViT、阶段一条件交互/Decoder 仍可学习图像损失。**仅 BF 的 `L_H/J` 为无效项，不可伪造**。
- 若 `P0` 过度低通导致细短笔画拓扑消失，应**先记录并请用户审阅图像**，不可私加大幅高频损失改变粗图目标；允许配置小范围低通参数用于正确性检查，正式数值实验需用户批准。

### 3.2 阶段二：在 `P0` 上执行 BF 局部 MAE 重建

$$
\begin{aligned}
\mathcal{L}_{1}={}&
\lambda_{\mathrm{img},1}\mathcal{L}_{\mathrm{img}}(P_1,GT)\\
&+\mathbf{1}_{BF}\lambda_{\mathrm{bf}}\mathcal{L}_{\mathrm{bf\text{-}local}}(P_1,GT;M_{\mathrm{pixel}})\\
&+\mathbf{1}_{JT}\lambda_{J,1}\mathcal{J}(P_1,GT).
\end{aligned}
$$

完整图损失采用 Run B Fix 的三类**构成**，但在新输出上重算并重新标定权重：

$$
\mathcal{L}_{\mathrm{img}}=
\mathcal{L}_{\mathrm{SmoothL1}}^{\mathrm{full}}
+\lambda_{\mathrm{gram}}\mathcal{L}_{\mathrm{VGG\ Gram}}^{\mathrm{full}}
+\lambda_{\mathrm{edge}}\mathcal{L}_{\mathrm{edge}}^{\mathrm{full}}.
$$

局部 BF 损失初版：

$$
\mathcal{L}_{\mathrm{bf\text{-}local}}=
\mathcal{L}_{\mathrm{SmoothL1}}^{M_{\mathrm{pixel}}}
+\lambda_{\mathrm{edge,local}}\mathcal{L}_{\mathrm{edge}}^{M_{\mathrm{pixel}}}.
$$

具体实现要求：

- `L_img(P1)` 监督完整目标字，保持原图背景与整字拓扑；`L_bf-local` 只在训练时选择的 BF 语义遮盖对应区域生效，GT 只用于 loss。
- 局部 Smooth-L1 的分母应按 `M_pixel ∩ valid` 的有效像素数归一，避免 11 层实际面积波动导致权重漂移；空 mask 安全输出数值 0 并记录样本。
- edge 的局部 mask 需处理 Sobel/Gaussian 核边界，以免人工遮盖边界被错误当作 GT 笔锋。记录所采用的“先计算整图 edge 再 mask / mask 区域膨胀后裁边”等实际实现。
- `J(P1)` 对**双标注**生效，梯度更新 BF Refiner 使其不破坏结构；阶段二 JT Head 冻结，`L_H` **只计算监控指标，不参与有效反传**，不必把乘零的 `L_H` 加入优化器。
- 不能使用原来只对 mask 区域求像素误差的 `forward_loss` 代码就声称已计算“最终全图损失”；检查目标下半整个字的有效像素范围、上半参考区、VGG 输入复原与归一化。
- 新增 `lambda_low`、`lambda_J0`、`lambda_H`、`lambda_img1`、`lambda_bf`、`lambda_J1` 及局部 edge 权重都**未经标定**；在真实模型梯度探针后才确定。旧 `lambda_full/w_J/w_H` 不得直接搬过来。
- 不启用额外 GAN、Tip、新 detail loss；后续单变量消融再论证。

## 4. 训练阶段、冻结与梯度拓扑

### 4.1 阶段 I：先训结体

- 从**已核验的 Run B Fix** 开始，在新开关下训练 JT Head + 阶段一条件交互 + 粗图路径，并在实际可训练配置下决定 ViT/原 Decoder 是否参与更新；不得无依据地“全解冻所有模块”。
- 三池均使用阶段一**目标下半全遮**部署条件，BF-only 对头部梯度隔离，但图像损失有效。
- **停止门槛不是一个未经验证的头部 IoU 常数**。输出 JT Head 占用 soft IoU/匹配、角色分类、尺度 `logσ`、质心；同时输出**真正 `P0` 的 JT 尺度、相对位置、形状/J**，看两个层面是否均达到可用精度。重点复查夸张部件横纵比例。
- 首轮可做有限 smoke / 小样本 overfit，**未获用户确认阶段一精度合格前不得自动切到阶段 II 长训**。

### 4.2 阶段 II：冻结阶段一，训练 BF Refiner

- **冻结阶段一全部参数**：MAE 主 ViT、JT Head、原融合/条件适配器、Coarse Renderer/阶段一 Decoder；这些参数不进阶段二 optimizer。
- 每个训练样本仍**实际执行阶段一**得到 `P0`、`S`，可用 `torch.no_grad()`（但必须保证 `train/eval`、归一化、增强、checkpoint 与后续推理行为一致）。**不能把 GT 低通图缓存来代替 `P0`**。
- BF Refiner 可以调用冻结的 ViT / MAE 计算与原 Decoder 权重，但需有**新建且实际可训练**的 Adapter/细化头。需要源码审计给出合理接口；不得因为共享冻结而使 `L_bf-local` 对全部参数无梯度。
- `P1` 从 masked `P0` 与部署可用参考、预测 `S/Q` 等产生。第二阶段对结构头零梯度，但局部与 `J(P1)` 应对 BF Refiner 有非零、有限梯度。
- 用双标注和 BF-only 训练笔法，`J(P1)` 仅在双标注计算；JT-only 默认只用作阶段一数据，避免无 BF 标注情况下暗自使用 GT 语义遮盖。
- 如参数冻结或输出缓存导致 loss 无有效梯度、前向输入包含 GT 或推理路径出现数据分支，视为**阻断性错误**。

### 4.3 概念梯度矩阵

| 阶段 / 损失 | MAE ViT（阶段一） | JT Head | 阶段一条件交互/Coarse | BF Refiner |
|---|:---:|:---:|:---:|:---:|
| I：`L_low`（有 JT） | 按训练冻结配置 | 可经条件路由更新 | ✓ | 未启用 |
| I：`L_low`（BF-only） | 按训练冻结配置 | **不得更新** | ✓ | 未启用 |
| I：`J(P0)`（JT 有效） | 按训练冻结配置 | ✓ | ✓ | 未启用 |
| I：`L_H`（JT 有效） | 按训练冻结配置 | ✓ | 按实际图审计 | 未启用 |
| II：`L_img(P1)` | **冻结** | **冻结** | **冻结** | ✓ |
| II：`L_bf-local(P1)` | **冻结** | **冻结** | **冻结** | ✓ |
| II：`J(P1)`（双标注） | **冻结** | **冻结** | **冻结** | ✓ |

注：具体是否能让 `L_low` 更新 JT Head 取决于 `S/Q` 的可微路由和冻结配置；**不得把图上连线误写成自动有梯度**。纯 BF batch、纯 JT batch、双标注、混合 batch 逐一核验实际参数梯度。DDP static_graph 的未使用参数/乘零路由问题必须按当前代码版本处理。

## 7. 必须显式保留的风险与未决项

1. **训练-推理 mask 不一致：用户已允许暂缓解决。** 训练 11 层来自 CalliPhase BF GT annotation，推理来自预测 `S/P0` 的自动分块，语义和覆盖率不等价；必须在报告中醒目标注，不得称“训练推理严格一致”。
2. **低频 `P0` 的拓扑问题**：高斯低通可能抹除短细画和使笔画连通性失真；结构精度验收必须同时看实际 `P0`，不能单看 `L_H`。
3. **JT Head 准确 ≠ P0 正确**：头的 soft IoU 高不代表粗图夸张部件的真实尺度正确；两个层面都要验收。
4. **训练阶段二只有 BF 标注池**：JT-only 未被私自转换成伪 BF；双标注可训练 `J(P1)`，其余 JT-only 仍有效参与阶段一。要改变这个策略先询问用户。
5. **原 Run B S/Q 的依赖可能被忽略**：先至少用只读诊断/后续消融记录条件响应，不得以“模块接上就有效”作为结论。正式 no-S/shuffle 消融留后期。
6. **条件交互具体结构、低通滤波参数、loss 权重、阶段切换门槛、推理自动分块调度** 尚未获得单独数值定案：允许做不改变目标的最小实现与 smoke；涉及大范围架构选择或长训超参时先提交候选给用户选择，不得以 agent 自己的猜测充当决定。
7. **冻结共享 MAE 后，阶段二必须有独立可训练参数**。若仅调用原冻结 ViT/Decoder，loss 即使有数值，也不会优化细化能力。
8. **先生成 P0 再遮盖属于最新研究方向，尚无已验证收益**；历史 A3/A4 人工扰动导致的断笔不是本模型训练失败证据，不得混淆。
